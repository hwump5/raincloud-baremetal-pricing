雨云把这类产品叫"裸金属物理机"（Rain Bare Metal，简称 RBM）。它和普通云服务器最大的区别就一句话：没有 KVM 那一层，应用直接调度物理硬件。你自己决定装什么系统，也可以在上面再开虚拟化。

## 先确认：雨云的物理机是"真独享"吗

这个问题值得先回答，因为市面上确实有把 VPS 换个名字叫"裸金属"的商家。

按官方文档的说法，RBM 提供单租户独享底层物理硬件资源，用户完全独享一台物理服务器的所有性能，可以自由安装操作系统、开虚拟化。论坛里 2024 年的产品公告也直接回应过这件事：雨云卖的是真物理服务器，只是通过自动化技术让物理机像云产品一样被管理。

落地到一个具体机器上看，第三方测评拆过宁波那台 AMD 8745HS 机型，主板是天钡 GEM12 小主机，硬盘西数 WD Blue SN580 500G，网卡 Intel I226-V 2.5G，内存是英睿达单条 32G DDR5 5600。远程管理用的是 NanoKVM，能进 BIOS（雨云给 BIOS 设了密码）。测试里虚拟化架构一栏显示的是 Dedicated，不是 KVM。

## 机型怎么挑：五个系列，对应五种活儿

官方购买指南把机型分成五类，选型逻辑其实挺清楚——先看你的业务吃单核还是吃多核。

**E5 通用型**：Intel 至强 E5 经典系列，多核性能强，官方给的定位是"高性能需求的中等体量网站"。三个配置：

- 基础型 v3：2×E5-2650L v3，32G 内存，480G SSD
- 标准型 v4：2×E5-2650 v4，64G 内存，480G SSD
- 专业型 v4：2×E5-2680 v4，64G 内存，960G SSD

**铂+金 专业型**：Intel 铂金/金牌系列，多核性能最强的一档，适合中大体量网站、虚拟化、高算力任务。内存直接从 128G 起步，最高 256G。

**Intel 超频游戏型**：官方说法是"大师特调、爆改水冷液金超频"，i7 14700HX（64G 内存）和 i9 14900KS（128G 内存）两款，适合 MC 大型服务器和整合包这种死磕单核的场景。

**AMD 游戏型**：Ryzen 8745HS，32G 内存配 500G SSD。定位是中型 MC 服、中高主频需求的游戏服务端。这台机器单核性能不弱，第三方测评跑出过 Geekbench 单核 2201、多核 20717 这一档的成绩。

**Mac Mini**：M4 芯片，16G 或 32G 内存配 256G 硬盘。官方列的适用方向是高性能 MC 服、开发、AI、设计和 CI/CD，算是个比较少见的选择。

## 价格由四样东西决定，不只看 CPU

同一个 E5 标准型 v4，宁波 588 元、深圳 540 元，差价来自线路和防御。搞明白下面四项，你大概能算清自己的账单。

**第一项：区域和线路。** 目前能买到物理机的节点包含浙江宁波、浙江温州、浙江绍兴、湖北十堰、广东深圳、中国香港、日本东京。国内几个区域里，深圳还分电信和腾讯 BGP 两条线路，价格差距不小。

**第二项：带宽与流量类型。** 雨云物理机分"大带宽限流量型"和"小带宽但不限流量型"，同一个配置两种类型价格一样。举个例子，宁波那台 8745HS 大带宽款给到 500Mbps，不限流量款上传带宽是 50M。选哪边取决于你是短时跑满还是长期低负载。

限流量型有个比较实用的设计：**当月用不完的流量可以叠加到下个月，不清零**。流量用完后会限速到 5Mbps，可以买流量包恢复高速。流量包的单价按区域不同，宁波是 35 元/1TB，深圳是 100 元/1TB。

**第三项：防御。** 宁波电信 100G 防护的 IP 加购价 30 元/个，联通 100G 是 100 元/个。香港的高防 IP 是 40 元/个，普通无防御直连 IP 只要 5 元/个。十堰那款基础型 v3 本身就带了 800G 高防电信（含 UDP 和海外优化），这也是它 498 元的价格里比重不低的一部分。

**第四项：硬件定制。** 这里要注意一个前提条件：**只有季付及以上的物理机才能做硬件定制**。常规定制 24 小时内完成，需要专门采购硬件的 72 小时内交付。

## 下单前值得确认的几件事

**系统能装什么。** 官方支持 Ubuntu 22.04/24.04、Debian 12、CentOS 7、Rocky Linux 8/9，以及 Windows Server 2018/2022/2025 数据中心版，全自动安装并激活。想装别的也不是不行——物理机给你的是完整硬件控制权，还可以自己去 BIOS 里折腾（BIOS 有密码，需要联系客服）。

**IP 怎么加。** 默认带 1 个 IPv4，可以免费附加多个 IPv6 地址。IPv4 支持加购，早期公告提到最多可附加到 30 个，不同区域的高防 IP 加购价前面已经列过了。

**能不能监控。** 可以。物理机有完整的资源监控，CPU、内存、网络速度、CPU 温度、硬盘读写、硬盘健康状况都做成图表，不用靠猜。

**什么时候别选物理机。** 如果你的业务访问量波动大、需要频繁扩缩容，云服务器更合适——物理机是按整台租的，配置调整依赖工单和定制交付，不是点一下就变。反过来，只要你的业务对单核性能、IO 稳定性或者"邻居不抢资源"有硬要求，物理机的钱花得就值。
